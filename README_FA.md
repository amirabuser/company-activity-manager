# ردیاب فاکتورها — پروژه Native اندروید
این فایل APK نیست. پروژهٔ Android Studio است و برای ساخت APK نیاز به Android SDK، Gradle و اینترنت برای دریافت وابستگی‌ها دارد.

## ساخت APK
1. پوشه پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync انجام شود.
3. از Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کنید.
4. خروجی معمولاً در app/build/outputs/apk/debug/app-debug.apk قرار می‌گیرد.

## امکانات نسخه ۱
- ذخیره نوبت‌های تحویل در SQLite خصوصی دستگاه
- جست‌وجوی استان و چاپخانه
- تایم‌لاین رویدادها و زمان خودکار با نمایش شمسی
- ثبت علت نقص و تصمیم مدیر فروش
- پیوست عکس دریافت و فیش واریزی، کپی‌شده در فضای خصوصی برنامه
- گزارش CSV قابل بازکردن در اکسل

## محدودیت‌های نسخه آزمایشی
- خروجی CSV فقط اطلاعات متنی دارد و تصاویر را همراه خود خروجی نمی‌گیرد.
- بکاپ و بازیابی کامل هنوز پیاده‌سازی نشده؛ حذف برنامه، داده‌های محلی آن را پاک می‌کند.
- هنوز روی دستگاه واقعی و کامپایل Android Studio آزمایش نشده است.
- پرداخت تجمیعی با پیوست عکس تکراری قابل ثبت است، اما ارتباط مشترک مستقل بین پرونده‌ها ندارد.
- برنامه فقط برای استفاده شخصی آفلاین است.
